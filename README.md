# Personal Finance Assistant

A personal finance assistant to record transactions, keep an account balance, and
get simple savings and investment suggestions.


## Installation

```
git clone https://github.com/sed-mirzaee/Personal-Finance-Assistant.git
cd Personal-Finance-Assistant
uv pip install -e .
```

## Usage
```
uv run -m personal_finance_assistant 
```
